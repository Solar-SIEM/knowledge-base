# Диагностика и управление кластером Kubernetes через k9s

Основным инструментом для мониторинга, сбора метрик и устранения инцидентов в кластере Kubernetes является терминальный UI **k9s**. Он автоматически устанавливается вместе с SIEM и заменяет рутинные команды `kubectl`, позволяя в реальном времени отслеживать состояние подов, анализировать логи, «проваливаться» в shell контейнеров и быстро перезапускать упавшие сервисы.

---

### Навигация

* `:` — командная строка (как в Vim)
* `/` — поиск
* `?` — справка по горячим клавишам
* `Ctrl` + `a` — показать все namespaces
* `0`–`9` — быстрое переключение между namespaces

### Просмотр ресурсов

Команды вводятся через `:` в командной строке:

| Команда | Описание |
| --- | --- |
| `:pods` / `:po` | Список подов |
| `:svc` | Сервисы |
| `:deploy` | Деплойменты |
| `:ns` | Пространства имен (Namespaces) |
| `:nodes` | Ноды кластера |
| `:events` | События кластера |
| `:secrets` | Секреты для сервисов |
| `:configmaps` | Просмотр настроек сервисов |
| `:statefulsets` | Работа со Stateful-сервисами |
| `:crds` | Custom Resource Definitions |

### Горячие клавиши для подов

* `Enter` — детальная информация
* `l` — логи пода
* `s` — shell (терминал) внутри контейнера
* `d` — вывод команды `describe`
* `e` — редактирование YAML-манифеста (`edit`)
* `y` — просмотр YAML-манифеста
* `Ctrl` + `k` — удалить (убить) под (полезно для быстрого перезапуска)
* `z` — перезапуск всех зафейленных (красных) подов
* `Shift` + `n` / `c` / `m` — сортировка по имени, CPU или памяти соответственно

### Фильтрация и поиск

* `/` — поиск по текущему списку
* `f` — фильтр по лейблам (labels)
* `Ctrl` + `/` — нечеткий (fuzzy) поиск

### Работа с логами

* `l` — открыть логи пода
* `0` — логи всех контейнеров
* `1`–`9` — логи конкретного контейнера
* `w` — перенос длинных строк (wrap/unwrap)
* `f` — стриминг в реальном времени (follow-режим)

### Полезные лайфхаки

* **Быстрое переключение контекстов:** `:ctx` → выбор нужного контекста клавишей `Enter` *(все сервисы системы расположены в контексте `aegis`)*.
* **Мониторинг в реальном времени:** `:pods` + `a` — автообновление списка.
* **Массовые операции:** выделите несколько ресурсов клавишей `Space` (пробел), затем выберите необходимое действие.
* **Быстрая проверка деплоя:** `:deploy` → `Enter` на проблемном ресурсе → `r` (связанные ресурсы).
* **Дашборд состояния кластера:** `:pulses`
